What Changed?

LLMs can write code — everyone knows that by now

But: Agents can also plan, structure, and execute code autonomously

The shift: from "AI as autocomplete" to "AI as a coworker who works independently"

How We Build Software — Today

"So sieht Software-Entwicklung heute aus: Business gibt Requirements rein, der Dev hat seinen lokalen Loop, reviewt wird von einem anderen Dev, CI läuft, und am Ende deployed wieder ein Mensch. AI assistiert nur beim Tippen."

What if Coding Was a Factory?

"Gleiche Bausteine: Coding, Integration, CI, CD, Review. Aber schaut wer was macht: der Agent coded, integriert, und fixt sich selbst wenn CI fehlschlägt. Der Mensch schreibt den Spec und reviewt am Ende. CD deployed automatisch nach Approval."

Why Build Your Own?

Offload compute from the laptop

Agents work async — even while you sleep

Codex, Copilot Agent, Devin go there — DIY teaches you what's real

Self-experiment: how far can you push it today?

Chapter 2

Internals of a Coding Factory

The Factory — Schematic

"Hier seht ihr alles zusammen: Control Plane oben — da sitze ich. Execution Plane unten — da arbeitet der Agent, eingepackt wie eine Matroschka. Lateralus ist geplant, noch nicht gebaut — deshalb gestrichelt."

The Control Plane

Happier — Start sessions, monitor progress, intervene (Web + iOS)

Lateralus — Orchestrator for multi-agent runs (planned)

GitHub — Source of truth: Issues, PRs, Code

You define what gets built. The control plane makes it happen.

Happier — The Control Interface

Web + iOS app — relay to the coding factory

Start sessions from a GitHub Issue or prompt

Monitor agent progress in real-time

Intervene: cancel, redirect, or approve

You'll see this in action in the demo.

"Happier ist quasi mein Remote für die Factory. Ich starte Sessions, sehe was der Agent tut, und kann jederzeit eingreifen. Gleich zeig ich euch das live."

The Execution Plane

Ubuntu VM — Homelab or cloud

Bubblewrap — Sandbox container, restricted network

Schism — CLI shim that blocks destructive/expensive commands (human-in-the-loop)

Agent (Kiro / OpenCode) — Reads spec, plans tasks, writes code, commits

Matroschka: VM → Bubblewrap → Schism → Agent. Each layer adds safety.

"Wie eine Matroschka: jede Schicht fügt Sicherheit hinzu. Der Agent darf bauen, aber nicht ausbrechen."

Chapter 4

Key Takeaways & Outlook

① We're Just Getting Started

You can build your own coding factory — today

Vendors are productizing it: Codex, Cursor, Github, Multica, etc.

The patterns are emerging — coding factories will become a commodity

② The Skills That (Still) Matter

Systems thinking

Distributed systems & clean architecture

Unix fundamentals

Can't review what you don't understand

15 years of building systems without AI — that foundation still matters

③ LLMs Are Not Intelligent

Stochastic — plausible, but no understanding

Security holes

Hallucinated libraries

Inefficient approaches

The agent is only as good as the senior who reviews

10× faster code means
10× faster problems —
in socio-technical systems, speed alone isn't the answer.
